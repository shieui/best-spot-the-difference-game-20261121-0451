Lantern Lane is an original spot-the-difference game: two near-identical pictures side by side, seven differences hidden in each scene, and a clock counting down. Three hand-drawn scenes — Moonlit Garden, Harbor at Dawn, and Night Market — each with seven fair-but-sneaky differences, a hint system with riddles, combo scoring, a time bonus, and synthesized chimes (no audio files). Click a difference in either picture to ring it; wrong clicks cost 5 seconds. Everything — art, sounds, names — is original and drawn in code with the canvas 2D API.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
